## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-pick-epub`
- `allow-pick-folder`
- `allow-scan-document-tree`
- `allow-open-document-read`
- `allow-read-document-chunk`
- `allow-close-document-read`
- `allow-install-model-pack`
- `allow-synthesize`
- `allow-platform-status`
- `allow-set-system-bars`
- `allow-background-app`
- `allow-perform-haptic`
- `allow-play-audio`
- `allow-control-audio`
- `allow-audio-status`
